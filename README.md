# IMU-board
Im making a module that has small sensors on the pcbs, which will give me motion data, which i will track and recieve on either my phone or computer using the usb-c. i have planned to use components to measure acceleration, and gestures, etc. i have done some research, and i have decided to use the ST ISM330DHCXTR which can be found from LCSC electronics.
I want for instance to test this when im inside the car, and i want to see what data it will provide me, and whether it is accurate compared to my phone (and possibly whether my phone is accurate compared with it ;).
